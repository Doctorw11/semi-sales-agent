# 半导体销售陪练陪跑

给半导体 ToB 销售新人用的本地工具。核心是一个会调用工具的 agent，加三个陪跑模块。

要回答的问题只有两个：**客户在哪、怎么开口。**

## 怎么用

双击 `index.html` 就能打开，不需要安装任何东西，不需要联网。

数据存在浏览器本地（localStorage），不上传。换浏览器或清缓存会丢，重要数据用「陪跑 → 导出」存一份。

开发时用 `npm run dev` 起本地服务，`npm test` 跑冒烟测试。两者都是零依赖。

## 六个模块

### 今天

默认首页。回答一个问题：**今天该打哪几个电话。**

待办不是手动列的，是从数据里自动算出来的：项目卡上过期的跟进、分数够高但从没联系过的公司、14 天没有接触记录的项目。每条都能一键跳到对应的项目卡或目标公司。

旁边是本周节奏：近 7 天打了几个电话、发了几条微信、见了几次面、送了几次样、报了几次价、跟了几个测试。**没开单的月份，这些数字就是你的进度。**

右上角两个入口：「记一笔」记录一次真实动作，「我卡住了」打开卡点诊断。

### 卡点诊断

六个分支：没有客户、有客户没需求、有需求没送样、送了样没结果、有报价没下单、有订单没回款。每个分支给 4 条具体动作，并指出该去看哪一节内容。

新人最痛苦的不是没方法，是不知道自己卡在哪一步。先定位，再使劲。

### Agent

给它一家公司名或一句话，它就跑一遍：查本机台账 → 建/改档案 → 定位产业链层级 → 算采购意向分 → 起草开场话术 → 给下一步。中间每一步工具调用都在对话里可见，不是黑箱。

**它真的会动手**，不是只会聊天。可调用的工具：

| 工具 | 作用 |
|---|---|
| `list_industry_chain` | 列出 10 层产业链，判断目标在哪一层 |
| `search_companies` | 查本机已录入的公司 |
| `get_company` | 取单家公司的完整档案 |
| `create_company` | 新建档案（会拦截重复创建） |
| `update_company` | 更新字段 |
| `list_signals` | 列出全部采购意向信号 |
| `score_intent` | 按信号算分 |
| `draft_outreach` | 按渠道起一版话术 |

配置了大模型就走真正的 function calling 循环：模型决定调哪个工具、传什么参数，程序执行后把结果喂回去，最多 6 轮。没配就走本地降级模式，只能查本机台账，会明确告诉你它没联网。

**一条硬规则写进了系统提示**：它没有联网能力，不准编造工商信息，也不准说"我查过了"。查不到就让用户自己去企查查或爱企查查。宁可空着，不准编。

侧栏还有一个「复盘一段对话」：把真实的微信聊天、邮件或通话记录粘进去，它会指出哪句丢了主动权、哪句把天聊死了、下一句该怎么接。没配模型时走本地规则检查，并明确标注"不是 AI 判断"。

### 找客户：先定位，再筛选，最后才开口

这个模块分三页，顺序不能反。

**产业链地图** — 解决"去哪找"，是整个应用里信息密度最高的一页，分五块：

1. **主链 10 层**：材料与设备 → EDA/IP → 芯片设计 → 晶圆制造 → 封装测试 → 器件元件模组 → 方案商 → ODM 代工 → 品牌整机 → 行业工程商。每层写清细分、谁在这、买什么、卖给谁、新人能不能进。
2. **芯片品类 9 类**：模拟、数字/SoC、存储、MCU、功率、射频、传感器、CIS、分立器件与被动件。每一类给代表厂商和生意特点（比如存储是强周期、MCU 换了要重写代码）。
3. **品类上下游 12 个**：显示模组、摄像头模组、被动元件、通信模组、功率器件、结构件、模拟芯片、MCU、存储、射频前端、传感器、先进封装。每个按"上游 / 你这一层 / 下游"拆，末尾给一句新人切入点。
4. **下游应用 8 个**：消费电子、汽车、工业、通信、数据中心/AI、新能源、安防、医疗。每个写清做什么、用什么芯片、代表客户、打法差异。
5. **客户类型 6 类**：品牌整机、ODM/EMS、IDH 方案商、模组厂、工业设备厂、工程商。给出各自的决策链。

页面最上面是三个自问自答：我卖的这颗料是谁做出来的、最后装进谁的产品、每两个环节之间谁在求谁。

**目标公司** — 解决"这家值不值得打"。每家公司一张卡，分两部分：

- 工商信息：统一社会信用代码、注册资本、成立时间、参保人数、注册地址、有没有生产场地、经营范围、产业链位置、在招岗位。**参保人数比注册资本真实得多**，注册资本可以随便写，参保人数是实缴社保的人。
- 采购意向信号：7 条强信号（在招采购岗、在招研发岗、发新品、扩产、参展、中标、融资）+ 7 条中信号（参保 100 人以上、成立 3 年以上、有厂房、经营范围对得上等）+ 5 条负信号（注册地在写字楼、参保不到 10 人、有失信记录等）。

勾选后自动打分。分数按 5 条强信号为满分折算，65 分以上标「优先打」，35 到 65 标「可以打」，低于 35 标「先放着」。负信号直接扣分。

支持 **CSV 批量导入**：一行一家公司，带表头（公司名称、产业链位置、主营产品、参保人数、成立时间、注册资本、注册地址、经营范围、在招岗位、备注），没有表头就按第一列当公司名。重名的自动跳过。

**怎么开口** — 5 个可以直接抄的模板（电话开场、微信加好友、邮件触达、被拒绝时怎么接、客户说"发资料吧"怎么回），加一张跟进节奏表（当天 / 第 2 天 / 第 5-7 天 / 第 14 天 / 第 30 天 / 长期），每个节点写清做什么、为什么这么做。

### 陪练

9 个新人一定会遇到的场景，每个场景对方连问 3 到 4 轮：

1. 第一次陌生电话
2. 研发追问：跟现用方案比优势在哪
3. 客户说：我们一直在用别家
4. 采购要你降 10%
5. 交期太长被对手压
6. 老板盘你的项目
7. 客户说：先放一放
8. 绕到对的人那儿去
9. SQE 追问批次一致性

每轮答完立刻给四样东西：命中了哪些动作、漏了哪些动作、踩了哪些坑、一句参考说法。

评分是关键词规则算的，不是大模型猜的。所以分数稳定、可复现，同一个回答每次都是同一个分。内置 28 轮追问、57 条考察动作、30 条踩坑规则；9 个场景的参考答法全部自测满分，112 次敷衍回答里只有 1 次碰到 50 分。

### 陪跑

每个项目一张卡，按 8 个阶段走：线索 → 技术交流 → 送样 → 测试验证 → Design-in → Design-win → 小批量 → 量产。

项目卡有四个页：

- **事实**：每个阶段有"至少要知道的事实"。填不满的格子，就是你在客户那儿没问出来的东西。
- **流程**：订单从客户开发到回款的 12 步链路，可以逐步勾选；附三条卡住时的升级路径（研发 / 生产交付 / 品质），和一个议价计算器。
- **拜访准备**：根据项目卡自动生成这次见面必问的几个问题，外加基于阶段和缺失信息的风险提示。
- **记录**：结构化写一次复盘，自动更新项目卡和跟进日期，形成接触记录。

**议价计算器**是这个版本新加的，也是最该先用的一个。它的逻辑：降价吃掉的是纯利润，毛利 20% 的料降 5%，毛利率直接剩 15%。输入现价、现毛利率、我方份额、客户要的降幅、降价后份额，它会算出销售额和毛利额的前后对比，还会反推"要保住原来的毛利额，份额至少要拿到多少"。客户说"降 5% 给你加量"的时候，先用这个算一遍，很多看起来很划算的方案当场就露馅了。

列表按危险程度排序：跟进过期的、14 天没动静的排在最上面。

### 底座

13 个小节，带搜索：术语速查、客户角色地图、项目阶段与卡点、内部协同、红线、前 90 天怎么过、内部资源地图、信息源清单，以及这五节：

- 入行：选品与选公司
- 入行：产品知识清单
- 入行：职业路径与薪资口径
- 商务招待的实操与红线
- 公司梯队名单（参考）

## 内容来源与可信度

陪练题库、底座前六节、阶段定义和 12 步流程，是我按半导体 ToB 销售的通用打法整理的。

底座的「选品与选公司」「产品知识清单」「职业路径与薪资口径」「商务招待」「公司梯队名单」五节，以及陪跑里的 12 步订单流程和三条升级路径，整理自一个做泛半导体原厂销售、带应届生的从业者的公开内容（抖音号 `64202157738`，账号名 Salesman）。

关于这部分要说明三件事：

1. **薪资数字是他的口径，不是统计结论。** 他给的 1-3 年 12–15k、3-5 年 15–20k 这类台阶，来自他本人和猎聘截图。当趋势看，别当承诺。
2. **公司名单部分由 AI 生成。** 他自己在帖子里承认用过豆包，也没做核实。名单只能当线索起点，投递前必须自己确认这家公司到底是不是原厂、有没有在招人。
3. **商务招待那一节写的是他观察到的行业现状，不是让你照做。** 合规红线一律以你公司的制度为准。

## 可选：接大模型

不填也能完整使用。填了之后多两件事：

- 每轮答完，教练会针对你这一句补充一条点评和一句可直接照说的改法。
- 整场结束给一条习惯层面的总结。

设置里填三项：接口地址、API Key、模型名。地址要写成 OpenAI 兼容的 `/v1` 形式，程序会自己拼 `/chat/completions`。

Key 只存在本机 localStorage。用 `file://` 打开时，如果接口不允许跨域，连接会失败，此时工具会自动退回离线引擎，不影响使用。

## 目录

```
index.html              页面结构
styles.css              样式
js/icons.js             内联图标（lucide 路径，离线可用）
js/data-scenarios.js    陪练题库与评分规则
js/data-playbook.js     底座内容、阶段定义、事实字段、产业链与意向信号
js/scoring.js           关键词评分引擎
js/app.js               主逻辑 + 对外 API
js/agent.js             Agent 循环、工具定义与执行
scripts/serve.js        零依赖本地服务器
tests/smoke.js          零依赖冒烟测试
```

想加场景就往 `js/data-scenarios.js` 里加一条，想加术语就往 `js/data-playbook.js` 里加。
