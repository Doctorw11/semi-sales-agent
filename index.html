陪练

挑一个真实会遇到的场景，对方会连问几轮。答完立刻给反馈。

左边选一个场景

建议从"第一次陌生电话"或"客户研发追问技术细节"开始。答得不好不要紧，难看的分数比舒服的空白有用。

陪跑

每个项目一张卡。填不满的格子，就是你在客户那儿没问出来的东西。

还没有项目

新建一张项目卡，把你手头跟的客户放进来。哪怕信息残缺，先建起来，缺什么一眼就看得到。

找客户

先看清产业链在哪一层找，再查工商筛意向，最后才是开口。

底座

术语、客户角色、阶段标准、内部流程、红线。遇到不确定就回来查。

设置

不填 API Key 也能完整使用，陪练走内置脚本引擎。填了之后对方由大模型扮演，回应更活。

大模型（可选）

Key 只存在本机 localStorage，不会发到除了你填的接口以外的任何地方。

数据

项目卡和陪练记录保存在浏览器本地。换浏览器、清缓存会丢，重要数据记得导出。
